#  Linked List Virtual Lab

An interactive, web-based visualization tool designed to help users understand how **Linked Lists** work through an engaging **train analogy**.  
Each node in the list is represented as a carriage in a train — allowing learners to see insertions, deletions, and traversals happen in real-time.

---

##  Project Overview

The **Linked List Virtual Lab** is built using **HTML, CSS, and JavaScript** with no external libraries or frameworks.  
The primary goal of this project is to simplify complex data structure concepts by making them visually intuitive and interactive.

Users can perform operations such as:
- **Insert at Beginning / End**
- **Delete from Beginning / End**
- **Reset the List**
- Real-time updates of the train visualization with smooth animations

This project serves as both an educational tool and a demonstration of front-end design, logical data handling, and DOM manipulation.

---

##  Objectives

- Provide an easy-to-use interface for experimenting with linked list operations  
- Reinforce theoretical data structure knowledge with live visual representation  
- Demonstrate clean separation of concerns among **Frontend**, **Logic**, and **Integration** modules

##  How It Works

1. **Input Section:**  
   The control panel allows users to input values and perform linked list operations.

2. **Visualization Area:**  
   Each node is represented as a carriage in a horizontal train. The head node appears as the engine, while subsequent nodes form the carriages.

3. **Dynamic Rendering:**  
   Every operation on the linked list updates the visualization in real time using DOM manipulation and CSS transitions.
